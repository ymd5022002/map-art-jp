抽出色地図アート 作成ツール

画像 → パレット抽出 → 地理院URL / CLR 出力

自動サンプリング（押すたび変化）／画像クリック手動サンプリング／カラーバー確認／確定→地理院表示（関東固定）／CLR（ColorMap 1 1 or Height）出力

1) 画像とサンプリング
手動: 画像クリックで色追加 削除: 色チップを右クリック
画像未読込
手動サンプリング

クリックした順にパレットへ追加します。反転ONなら先頭へ追加します。

自動生成（押すたび変化）

例: 自動抽出64色 → 補間256色 → ×4 で 1024色。地理院URL生成時も不足分は自動で繰り返しますが、ここで「美しい周期」を作ってから確定できます。

自動抽出は「画像内のランダム点群→色の代表値（簡易クラスタ）」です。重い場合は抽出点数を下げてください。

2) パレット確認 → 確定 → 出力
現在 0 色 確定 0 色

カラーバー上の色チップは下に一覧表示されます（右クリックで削除）。

内部仕様は「colors[] + minHeight + step」です。地理院URLはここから展開します。

まずは関東平野で段彩の見え方を確認、という前提で固定プリセットにしています。

色一覧（右クリックで削除）
左→右＝低→高（想定）

Tips: 右クリックで色を削除／ 「近似色を間引き」は類似色を削って扱いやすくします／ 地理院URLは reliefdata を生成して開きます（地理院側の仕様変更があれば追随が必要です）。
